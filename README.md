# Generador de Fixture · Mundial 2026

Herramienta web para generar imágenes del fixture del **Copa Mundial FIFA 2026** listas para compartir por WhatsApp.

## ¿Qué hace?

- Carga automáticamente los partidos del día (o del día siguiente) desde la API
- Muestra hora en **horario boliviano (UTC-4)**
- Detecta la fase y la fecha/jornada automáticamente en la Fase de Grupos
- Genera una imagen PNG de 1080px lista para enviar a grupos de WhatsApp
- Cubre todo el torneo: Fase de Grupos, Octavos, Cuartos, Semis, Final

## API utilizada

Los datos de partidos se obtienen desde **[football-data.org](https://www.football-data.org/)** — una API gratuita de fútbol que provee fixtures, resultados y estadísticas de competiciones oficiales como la Copa del Mundo FIFA.
